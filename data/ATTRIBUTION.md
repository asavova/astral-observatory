# Star catalogue attribution

The bundled star data comes from the **HYG Star Database v4.1**, compiled by
**David Nash / Astronexus** from the Hipparcos, Yale Bright Star and Gliese catalogues.

- Original HYG source: https://github.com/astronexus/HYG-Database
- Exact source used: https://github.com/astronexus/HYG-Database/blob/3bf37f4b2d5460e1278286320d1d62fab9b493c1/hyg/CURRENT/hygdata_v41.csv
- Data license: [Creative Commons Attribution-ShareAlike 4.0](https://creativecommons.org/licenses/by-sa/4.0/)

## Local files

- `hygdata_v41.csv`: unchanged original HYG v4.1 CSV (119,626 catalogue entries, all source columns). Kept locally so future telescope work can use proper motions, distances and identifiers without internet access.
- `hyg-full-v41.tsv`: 119,625 stars from 119,626 HYG v4.1 entries. The Sun was excluded because it is not a fixed star. The file retains the HYG identifier, right ascension, declination, apparent magnitude, B−V colour index and proper name. Missing magnitudes and colour indices use fallback values of 99 and 0, respectively. It was generated by `scripts/import_hyg.py`.
- `hyg-bright-v41.json`: the earlier 5,070-star subset (magnitude ≤ 6.0), adapted by [RTF22/Orrery](https://github.com/RTF22/Orrery/blob/master/src/data/stars/hyg.json) from the same HYG v4.1 catalogue. Its RA and Dec values are in degrees, and the fields are rounded. The original Orrery asset notes are at [ASSETS.md](https://github.com/RTF22/Orrery/blob/master/ASSETS.md).

Both are bundled for offline use. The Java prototype uses the full TSV when present, otherwise the smaller JSON sample.
